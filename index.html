VGG7 - AI Vehicle Classification System (Truck/Bus/Bike/Car)

A convolutional neural network project for classifying images into four categories, with evaluation using accuracy, precision, recall, F1-score, and a confusion matrix.AI vehicle classifier (TRUCK/BUS/BIKE/CAR) using custom VGG7 CNN - 7 layers, 3 Conv blocks with padding='same', 87ms CPU inference. Pipeline: 4032x3024x3 (36M) → resize to 128x128x3 (49k) → VGG7 → Softmax. Includes sensor-level understanding (photon→electron→voltage→pixel). Use: traffic/toll monitoring. Outcome: 60% accuracy, 30MB model, Flask deployed. Next: Indian truck dataset + OCR to reach 80%.
